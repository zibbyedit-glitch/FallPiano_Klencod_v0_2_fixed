# Fall Piano v0.2 — مشروع مناسب لـ Klencod IDE

## ما تحتاجه
- Klencod IDE حديث يدعم استيراد ZIP وبناء Flutter عبر GitHub Actions.
- اتصال إنترنت أثناء البناء.
- تسجيل الدخول إلى GitHub من داخل التطبيق عند الطلب.

## طريقة الاستخدام
1. نزّل `FallPiano_Klencod_v0.2.zip` إلى الهاتف.
2. افتح Klencod IDE واختر Import Project / Import ZIP (قد تختلف التسمية حسب الإصدار).
3. اختر ملف ZIP واستورد المشروع.
4. تأكد أن المشروع يظهر فيه `pubspec.yaml` و`lib/main.dart`.
5. استخدم خيار Build APK أو Build Android APK. اسمح للتطبيق بإنشاء مستودع GitHub أو ربط المشروع به إذا طلب ذلك.
6. إذا فشل البناء، افتح سجل Build وانسخ أول خطأ أحمر مع آخر 30 سطرًا.
7. بعد نجاح البناء نزّل APK من صفحة النتائج وثبّته من مدير الملفات، مع السماح بالتثبيت لهذا المصدر عند مطالبة أندرويد.

## الميزات الموجودة
- وضع أربعة مسارات ووضع ثمانية مفاتيح.
- اختيار ملف صوتي محلي ومحاولة تشغيله عبر مشغل الصوت.
- اختيار BPM، احتساب نقاط وتتابع، وصعوبة تلقائية/يدوية مبدئية.
- واجهة داكنة.

## حدود النسخة بوضوح
هذه نسخة Flutter تجريبية أُعدت لتكون قابلة للاستيراد في Klencod IDE. لا تستخرج نغمات الأغنية الفعلية ولا تقوم بتحويل الصوت إلى MIDI؛ يتم توليد مربعات إيقاعية تجريبية وفق BPM. كما أن التزامن الدقيق بين الموسيقى والمربعات يحتاج تحسينًا واختبارًا على الجهاز. لم يُنتج APK مسبقًا داخل هذه الحزمة؛ يجب بناؤه من Klencod IDE.
